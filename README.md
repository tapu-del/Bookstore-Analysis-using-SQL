# Bookstore-Analysis-using-SQL

## Project Overview
Analyzed a bookstore database using PostgreSQL to answer 5 business questions.

## Tools Used
- PostgreSQL
- pgAdmin

## Business Questions Answered
1. Which books are best-selling?
2. Who are the top customers by spending?
3. What is the monthly sales trend?
4. Which genre sells the most?
5. Which books are low in stock?

## SQL Skills Used
- SELECT, WHERE, ORDER BY
- JOIN (INNER, LEFT)
- GROUP BY, HAVING
- CTE (Common Table Expressions)
- Window Functions
- Aggregate Functions (SUM, COUNT)
